# English

## Summary

GLM-5.3 is Z.ai's flagship model for complex software engineering and agent work, released on 18 August 2026. It keeps the GLM-5.2 base model and gets all of its improvements from post-training; Z.ai reports a 50% gain over GLM-5.2 on its own Z.ai Code Bench and state-of-the-art open-model results on public benchmarks such as Terminal Bench 3.0. In MAblog's production-coding ranking it scores 54 on the Artificial Analysis Coding Agent Index v1.5, level with Muse Spark 1.3. GLM-5.3 accepts text input only, with a 1M-token context window and up to 128K output tokens. It is included for all GLM Coding Plan users, with plans from $18 per month, and the API costs $1.40 per million input tokens and $4.40 per million output tokens, with cached input at $0.26.

## Description

GLM-5.3 targets long-horizon coding and, unusually, cyber defence. Z.ai says its cybersecurity abilities improved faster than expected during post-training and reports the best result to date on the CyberGym vulnerability-discovery benchmark. It works as a coding model inside tools such as Claude Code, Kilo Code, Cline and OpenCode through the GLM Coding Plan, and directly through Z.ai's API.

## What's new compared with the previous version

- 50% performance gain over GLM-5.2 on Z.ai Code Bench (self-reported).
- Same base model as GLM-5.2; all improvements come from post-training.
- Stronger vulnerability discovery and exploitation results than GLM-5.2 (self-reported).

## Key capabilities

- 1M-token context window and up to 128K output tokens.
- Long-horizon software engineering and agent tasks.
- Cybersecurity work: code review and vulnerability discovery.
- Usable through the GLM Coding Plan in third-party coding tools and through the Z.ai API.

# Español

## Resumen

GLM-5.3 es el modelo principal de Z.ai para ingeniería de software compleja y trabajo con agentes, lanzado el 18 de agosto de 2026. Mantiene el modelo base de GLM-5.2 y obtiene todas sus mejoras del post-entrenamiento; Z.ai informa de una mejora del 50 % sobre GLM-5.2 en su propio Z.ai Code Bench y de resultados punteros entre modelos abiertos en benchmarks públicos como Terminal Bench 3.0. En la clasificación de código de producción de MAblog obtiene 54 puntos en el Coding Agent Index v1.5 de Artificial Analysis, igualado con Muse Spark 1.3. GLM-5.3 solo acepta entrada de texto, con una ventana de contexto de 1M de tokens y hasta 128K de salida. Está incluido para todos los usuarios del GLM Coding Plan, con planes desde 18 $ al mes, y la API cuesta 1,40 $ por millón de tokens de entrada y 4,40 $ por millón de salida, con entrada en caché a 0,26 $.

## Descripción

GLM-5.3 se orienta a la programación a largo plazo y, de forma poco habitual, a la ciberdefensa. Z.ai afirma que sus capacidades de ciberseguridad mejoraron más rápido de lo esperado durante el post-entrenamiento y comunica el mejor resultado hasta la fecha en el benchmark de descubrimiento de vulnerabilidades CyberGym. Funciona como modelo de programación en herramientas como Claude Code, Kilo Code, Cline y OpenCode mediante el GLM Coding Plan, y directamente con la API de Z.ai.

## Novedades respecto a la versión anterior

- Mejora del 50 % sobre GLM-5.2 en Z.ai Code Bench (resultado propio).
- Mismo modelo base que GLM-5.2; todas las mejoras proceden del post-entrenamiento.
- Mejores resultados que GLM-5.2 en descubrimiento y explotación de vulnerabilidades (resultado propio).

## Capacidades clave

- Ventana de contexto de 1M de tokens y hasta 128K de salida.
- Ingeniería de software y tareas de agentes a largo plazo.
- Trabajo de ciberseguridad: revisión de código y descubrimiento de vulnerabilidades.
- Uso mediante el GLM Coding Plan en herramientas de terceros y la API de Z.ai.
