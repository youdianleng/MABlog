# English

## Summary

Grok 4.7 is xAI's coding-focused frontier model, announced on 21 September 2026 and available the same day in Cursor and Grok Build, through the xAI API, third-party coding harnesses, model routers and cloud platforms. xAI says it uses a new, larger base model than Grok 4.6 and is served at the same price and speed. In MAblog's production-coding ranking it sits alone at source rank 3 with 56 points on the Artificial Analysis Coding Agent Index v1.5, six points behind the tied leaders. The API offers a 500,000-token context window, text and image input, function calling, web and X search, code execution and four reasoning levels, at $2 per million input tokens and $6 per million output tokens, a fraction of the leaders' price.

## Description

Grok 4.7 is the default model in xAI's Grok Build coding tool and is also offered inside Cursor. xAI positions it on price-performance for longer-running coding tasks and says it was trained to work natively with the Grok Bot harness for conversational and general knowledge work. The developer documentation lists structured output, function calling, web search, X search and code execution, with reasoning effort from low to xhigh. Its knowledge cutoff is May 2026.

## What's new compared with the previous version

- Uses a new, larger base model compared with Grok 4.6 (xAI).
- Served at the same price and speed as Grok 4.6 (xAI).

## Key capabilities

- 500,000-token context window; text and image input, text output.
- Function calling, web search, X search and code execution.
- Reasoning levels: low, medium, high (default) and xhigh.
- Default model in Grok Build; also in Cursor and the xAI API.
