# English

## Summary

Muse Image is Meta Superintelligence Labs' image generation and editing model, launched on 7 July 2026. Meta says it follows instructions faithfully, edits with precision and composes from multiple reference images, and that it can use tools such as code execution and web search to improve its results. It is available in the Meta AI app and on meta.ai, in Instagram Stories in the United States and in WhatsApp in a limited set of countries, with Facebook to follow. In MAblog's image ranking it is fifth with an Elo of 1112 ±10 in the Artificial Analysis Text-to-Image Arena, overlapping Nano Banana 2. It is by far the lowest-priced option in the list, at about $10 per 1,000 images at 1024×1024 as measured by Artificial Analysis on 2026-10-01, and is free to use in Meta's own apps.

## Description

Muse Image is Meta's first in-house image generator from its Superintelligence Labs, launched together with a preview of Muse Video. It integrates with the Muse Spark model family and uses agentic tool use, including code execution and web search, which helps with precise outputs and with grounding images in current information.

## What's new compared with the previous version

- Meta's first proprietary image generator, launched with a preview of Muse Video.

## Key capabilities

- Precise image editing that changes only what the user asks for.
- Composes elements from multiple reference images.
- Agentic tool use, including code execution and web search, integrated with Muse Spark.

## Resumen
