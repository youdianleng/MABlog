# English

## Summary

Grok Imagine Image 2.0 is xAI's image generation and editing model, made generally available on 7 August 2026 as the new Quality Mode on grok.com/imagine and in the Grok iOS and Android apps. Developers can call it in the xAI API as grok-imagine-image-2.0. xAI says it built the model to make images people can use in real creative work, with precise generation and editing. In MAblog's image ranking it is second with an Elo of 1154 ±12 in the Artificial Analysis Text-to-Image Arena; its source rank of 4–5 becomes second place here because higher entries were removed by the access and one-family-per-provider rules. Its comparable price is about $60 per 1,000 images at 1024×1024, as measured by Artificial Analysis on 2026-10-01.

## Description

Imagine Image 2.0 adds a higher-quality Quality Mode to Grok's image tools, built, in xAI's words, to make images you can use in real creative work. It is available to consumers in the Grok apps and on grok.com, and to developers through the same xAI API that serves Grok's language models.

## What's new compared with the previous version

- Becomes the new Quality Mode on grok.com/imagine and the Grok mobile apps (xAI).

## Key capabilities

- Image generation and precise editing.
- Available in Grok on the web, iOS and Android.
- API model ID: grok-imagine-image-2.0.
