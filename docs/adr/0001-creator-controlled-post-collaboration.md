# Creator-controlled post collaboration

Creators grant view-only or editing access separately for each post using the email addresses of existing MAblog users; an unregistered email is rejected with Email not found. Editors can save working drafts and explicitly submit changes for review; the creator approves or rejects each block separately, and changes reach readers only after approval. Editors may also propose canvas resizing, reviewed separately by the creator as a layout change. Editors cannot delete the post, manage access, or publish publicly. Only the creator can unpublish a post; doing so removes public visibility while retaining its existing access grants. Submitted changes remain available for creator review if the editor's access is later removed. When two submissions compete for the same block, the creator compares both, approves the preferred version, and the other is rejected automatically; pending changes to unrelated blocks are preserved. This supports collaboration while keeping the creator in control of each post's audience and reader-visible content.
