# Use a freeform canvas for post composition

Posts consist of individually editable content blocks with user-controlled width, height, position, rotation, and front-to-back layer order; each block can combine text, images, links, and videos. The overall canvas is also user-sized through a drag-based, crop-like interaction; shrinking it hides outside content without deleting it, and expanding it reveals that content again. Blocks can overlap, with Bring forward and Send backward controls. Content that exceeds a block's height scrolls internally while the block retains its chosen size. The user chose this model for greater visual freedom after finding the proposed WordPress-style content flow too static. On phones, the reading view preserves the composition, scales it to fit the screen, and permits zooming. The creator approves or rejects changes per block, and separately reviews editor proposals to resize the overall canvas. Competing versions of the same block are compared by the creator; approving the preferred one automatically rejects the other. Rendering technology remains undecided.
